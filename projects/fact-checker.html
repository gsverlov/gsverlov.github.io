Fact-checker for Chrome

JavaScript, Python, Claude Agent SDK, CSS Custom Highlight API

GitHub

Click the extension's button on any article and it underlines the claims Claude flags as false (red) or misleading (yellow). Hover over an underline to see why it was flagged.

How it works

The interesting constraint is that a Chrome extension can't run Python. So the extension pulls the article text out with Readability.js and passes it over native messaging, Chrome's way of talking to a program on your own computer. A small Python host sends the text to Claude through the Agent SDK and gets back each problem claim as an exact quote, a rating and a short reason.

Back in the page, each quote is located in the page's text (ignoring differences in whitespace, curly quotes and dashes) and painted with the CSS Custom Highlight API, so the page's own HTML is never changed. Hovering checks which highlighted range is under the pointer and shows its reason.
