Most scholarship searches return hundreds of listings a student doesn't qualify for, and every application wants its own essay. ScholarshipAI takes a student's profile, finds the scholarships that fit, and drafts an essay for the one they pick, built around strategies taken from past winning essays.

How it works

Matching. Claude pulls eligibility facts out of the profile (GPA, degree level, field), then rewrites the profile so it searches well. The rewrite is embedded and compared against the scholarship database in ChromaDB, filtered by eligibility, keeping the 15 closest. Claude then re-ranks those and returns the top 5.

Essays. Winning essays were grouped into strategy clusters ahead of time, like "overcoming adversity through family responsibility". For the chosen scholarship, Claude picks the clusters that fit it, keeps only the strategies this student's experiences can actually support, and writes a draft around one of them.

The React front end talks to a Node.js and Express server, which runs the Python matching and essay code as child processes.
