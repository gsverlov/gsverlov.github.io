App Factory

Python, LangGraph, Claude Agent SDK, Claude Code, Docker

GitHub

App Factory takes a one-line prompt and turns it into a complete working app. It's a team of AI agents: one plans the app, several build it in parallel, and others review and check it. I started from an open-source version that often failed on bigger builds and worked on making it ship reliably.

What I changed

  • Fixed how the orchestrator splits work across up to 6 parallel dev agents and merges what they build.
  • Made the orchestrator write a task-specific skill file for each dev agent at runtime, instead of giving every agent the same fixed prompt.
  • Added code review and security stages before an app ships.

How it works

A run starts when a Linear issue is created. A LangGraph state machine moves it through spec, architecture, development, review, QA and deploy, pausing at human approval gates that notify Slack. Every agent is a Claude Code session running in Docker, and the agents share one append-only memory file per ticket instead of messaging each other.
